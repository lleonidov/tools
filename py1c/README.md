# Тестовые обработки для Vanessa ADD

Каталог `py1c` содержит инструменты для подготовки тестов в формате внешних обработок 1С. Исходный тест хранится в одном файле BSL. Планируется собирать из него обработку EPF без запуска 1С и сохранять результаты в `build/test/` с учетом структуры исходных каталогов.

Все команды ниже выполняются из корня проекта. Для создания шаблона нужен Python 3. Скрипты сборки пока не реализованы: запуск пустых файлов не создает обработку и не выполняет поиск.

## addTestEPF.py

Создает BSL-шаблон теста для Vanessa ADD в `src/tests/<тип>/epf/<имя>.bsl`. Если каталог отсутствует, скрипт создаст его. Если файл уже существует, скрипт завершится с ошибкой и не перезапишет его.

Базовый запуск:

```bash
python3 py1c/addTestEPF.py МойТест
```

Будет создан файл `src/tests/integration/epf/МойТест.bsl`: по умолчанию используется тип `integration`.

Полный запуск:

```bash
python3 py1c/addTestEPF.py ПроверкаСложения unit "smoke, arithmetic" "Проверка сложения чисел"
```

Будет создан файл `src/tests/unit/epf/ПроверкаСложения.bsl`. Аргументы передаются по порядку:

```text
addTestEPF.py <Имя> [unit|integration] [Теги] [Комментарий]
```

- `Имя` - обязательное имя файла и часть имени тестовой процедуры. Допустимы русские и латинские буквы, цифры и подчеркивание; первый символ не может быть цифрой.
- `unit|integration` - тип теста; по умолчанию `integration`. Также принимается вариант `integretion`, который преобразуется в `integration`.
- `Теги` - необязательная строка, записывается в комментарий заголовка; по умолчанию пустая.
- `Комментарий` - необязательная строка для заголовка; по умолчанию пустая. Если комментарий нужен без тегов, передайте пустой аргумент `""` на месте тегов.

Шаблон содержит метаданные и идентификаторы обработки, процедуры `Инициализация` и `ЗаполнитьНаборТестов`, а также экспортную процедуру теста. Пример утверждения в ней закомментирован: после создания нужно написать проверки самостоятельно. Теги и комментарий записываются в файл как переданные строки.

## buildTestEPF.py

Назначение: собрать внешнюю обработку EPF из одного BSL-модуля без запуска 1С. Файл пока пустой, сборка не реализована. Формат входных параметров, путь и имя готовой обработки, зависимости и команды базового и полного запуска еще не определены.

## findBuildTestEFP.py

Назначение: найти исходные файлы тестов и запустить для них `buildTestEPF.py`. По задумке первый параметр задает каталог поиска, например `src/tests/`; учитываются только файлы, лежащие в каталогах `epf`. Результаты сборки должны размещаться в `build/test/` с сохранением структуры каталогов исходных тестов. Например, для исходного файла `src/tests/unit/epf/МойТест.bsl` соответствующий каталог сборки - `build/test/unit/epf/`.

Предполагаемый базовый вызов после реализации:

```bash
python3 py1c/findBuildTestEFP.py src/tests/
```

Сейчас файл пустой, поэтому эта команда ничего не ищет и не собирает. Дополнительные параметры и полный вариант запуска еще не определены; точные правила отбора файлов и имена результатов сборки предстоит определить при реализации.
